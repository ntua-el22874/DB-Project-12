# Εξαμηνιαία Εργασία Βάσεων Δεδομένων 2025-2026: Νοσοκομείο "Υγειόπολις"

**Ομάδα 12**

Το παρόν αποθετήριο περιέχει τον κώδικα (DDL, DML, Triggers, Queries) για τον σχεδιασμό και την υλοποίηση της σχεσιακής βάσης δεδομένων του Γενικού Νοσοκομείου «Υγειόπολης».

## 1. Σχεδιαστικές Επιλογές & Παραδοχές (Assumptions)
Λόγω κάποιων ασαφειών ή ελλείψεων στις αρχικές προδιαγραφές, προχωρήσαμε στις παρακάτω παραδοχές για να διασφαλίσουμε την ομαλή λειτουργία του συστήματος:

* **Μοντελοποίηση Προσωπικού (ISA Hierarchy):** Για την αποφυγή πλεονασμού, χρησιμοποιήσαμε έναν κεντρικό πίνακα `Staff` που περιέχει τα κοινά στοιχεία όλου του προσωπικού, και εξειδικευμένους πίνακες (`Doctor`, `Nurse`, `AdminStaff`) για τα ιδιαίτερα χαρακτηριστικά τους (π.χ. ειδικότητα γιατρών).
* **Ιατρικές Ειδικότητες:** Δεδομένου ότι δεν δόθηκε συγκεκριμένη λίστα, θεωρήσαμε ότι το νοσοκομείο απασχολεί τις εξής ειδικότητες: 'ΙΑΤΡΟΣ_ΕΠΕΙΓΟΝΤΩΝ_ΠΕΡΙΣΤΑΤΙΚΩΝ', 'ΙΑΤΡΟΣ_ΕΣΩΤΕΡΙΚΗΣ_ΠΑΘΟΛΟΓΙΑΣ', 'ΓΕΝΙΚΟΣ_ΧΕΙΡΟΥΡΓΟΣ', 'ΜΑΙΕΥΤΗΡΑΣ_ΓΥΝΑΙΚΟΛΟΓΟΣ', 'ΠΑΙΔΙΑΤΡΟΣ', 'ΑΝΑΙΣΘΗΣΙΟΛΟΓΟΣ', 'ΑΚΤΙΝΟΛΟΓΟΣ', 'ΠΑΘΟΛΟΓΟΣ', 'ΚΑΡΔΙΟΛΟΓΟΣ', 'ΟΡΘΟΠΕΔΙΚΟΣ_ΧΕΙΡΟΥΡΓΟΣ', 'ΝΕΥΡΟΛΟΓΟΣ', 'ΨΥΧΙΑΤΡΟΣ'.
* **Διεύθυνση Τμημάτων:** Κάθε διευθυντής γιατρός μπορεί να προΐσταται σε **ένα (1) το πολύ** τμήμα του νοσοκομείου.
* **Ιεραρχία - Επόπτες:** Αν ένας νέος γιατρός έχει επόπτη, αυτός ορίζεται κατά την πρόσληψή του. Οι "Ειδικευόμενοι" έχουν υποχρεωτικά επόπτη, ενώ οι "Διευθυντές" απαγορεύεται να έχουν.
* **Χρεώσεις Νοσηλείας (ΚΕΝ):** Το σύστημα υπολογίζει αυτόματα πρόσθετη χρέωση για τον ασθενή, μόνο στην περίπτωση που οι συνολικές ημέρες νοσηλείας του ξεπεράσουν τη Μέση Διάρκεια Νοσηλείας που ορίζεται από τον εκάστοτε κωδικό ΚΕΝ.
* **Υποχρεωτικά Πεδία:** Υποθέσαμε ότι σχεδόν όλα τα πεδία στους βασικούς πίνακες είναι υποχρεωτικά (NOT NULL), εκτός αν ορίζεται διαφορετικά, για τη διατήρηση της ακεραιότητας των δεδομένων.

## 2. Περιορισμοί και Triggers
Για να εμποδίσουμε την εισαγωγή λανθασμένων δεδομένων (ή την παράκαμψη των κανόνων μέσω Updates), υλοποιήσαμε μια σειρά από Triggers. **Όλα τα triggers έχουν γραφτεί τόσο για `INSERT` όσο και για `UPDATE` γεγονότα**, προστατεύοντας τη βάση σε κάθε σενάριο:

1. **Ασφάλεια Ασθενών (Αλλεργίες):** Απαγορεύεται η συνταγογράφηση οποιουδήποτε φαρμάκου αν ο ασθενής έχει καταγεγραμμένη αλλεργία σε κάποια από τις δραστικές του ουσίες.
2. **Έλεγχος Κλινών:** Απαγορεύεται η εισαγωγή ασθενούς σε κλίνη, αν η τρέχουσα κατάστασή της δεν είναι "FREE".
3. **8ωρη Ανάπαυση & Διπλές Βάρδιες:** Υλοποιήθηκε αυστηρός έλεγχος που αποτρέπει την ανάθεση διπλής βάρδιας την ίδια ώρα, αλλά και την έλλειψη 8ωρης ξεκούρασης (π.χ. συνεχόμενη εργασία από Απόγευμα σε Νύχτα της ίδιας μέρας, ή από Νύχτα σε Πρωί της επόμενης).
4. **Μέγιστα Όρια Βαρδιών:** Το σύστημα μπλοκάρει τις αναθέσεις αν ξεπεραστούν τα μηνιαία όρια: 15 για γιατρούς, 20 για νοσηλευτές, 25 για διοικητικούς.
5. **Νυχτερινές Βάρδιες:** Απαγορεύεται η ανάθεση περισσότερων από 3 συνεχόμενων νυχτερινών βαρδιών στο ίδιο άτομο.
6. **Διαχείριση Χειρουργείων & Επεμβάσεων:** - Απαγορεύεται η ταυτόχρονη χρήση της ίδιας αίθουσας για δύο διαφορετικές επεμβάσεις.
   - Απαγορεύεται η συμμετοχή ενός γιατρού σε δύο επεμβάσεις που επικαλύπτονται χρονικά.
7. **Έλεγχος Αυτο-εποπτίας:** Απαγορεύεται ρητά ένας γιατρός να οριστεί ως επόπτης του εαυτού του (κυκλική εξάρτηση).

## 3. Οδηγίες Εκτέλεσης
Για το στήσιμο της βάσης στο τοπικό περιβάλλον, ακολουθήστε την εξής σειρά εκτέλεσης των αρχείων SQL:

1. **`install.sql`**: Δημιουργεί το σχήμα της βάσης (Tables, Primary/Foreign Keys, Checks).
2. **`load.sql`**: Φορτώνει τα δεδομένα από τα καθαρισμένα CSV αρχεία. *(Σημείωση: Απενεργοποιεί προσωρινά τα Foreign Keys και χρησιμοποιεί `\n` ως line terminator για την αποφυγή προβλημάτων με CRLF/LF format των Windows).*
3. **`Triggers.sql`**: Ενεργοποιεί όλους τους κανόνες ακεραιότητας και τους επιχειρησιακούς κανόνες του νοσοκομείου.
4. Εκτέλεση των επιμέρους αρχείων με τα queries (Q1 - Q15).
