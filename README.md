-υποθέτουμε ότι υπάρχουν ακριβώς 3 διαφορετικοί δοιηκιτικοί ρόλοι: Διευθυντές, Γραμματείς και Λογιστές.
-υποθέτουμε ότι 2 τμήματα του νοσοκομείου δεν μπορούν να έχουν τον ίδιο διευθυντή.

-υποθέτουμε ότι οι κλίνες του νοσοκομείου κατηγοριοποιούνται βάση του αν ανήκουν σε μονόκλινο ή πολύκλινο δωμάτιο ή αν βρίσκονται σε μονάδα εντατικής θεραπίας.

-υποθέτουμε ότι μία κλίνη μπορεί να είναι είτε κατηλημένη, είτε ελεύθερη είτε υπό συντήρηση.
