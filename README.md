# DB-Project-12

##Ορισμένες προδιαγραφές δεν ορίζονται από το νοσοκομείο οπότε είμαστε αναγκασμένοι να κάνουμε ορισμένες υποθέσεις.

-υποθέτουμε ότι όλα τα πεδία είναι υποχρεωτικά, δεν υπάρχει κάποια πληροφορία που να είναι προαιρετική η ύππαρξη της. 

-υποθέτουμε ότι το νοσκομείο απασχολεί μόνο τις παρακάτω ειδικότητες Ιατρών: 'ΙΑΤΡΟΣ_ΕΠΕΙΓΟΝΤΩΝ_ΠΕΡΙΣΤΑΤΙΚΩΝ', 'ΙΑΤΡΟΣ_ΕΣΩΤΕΡΙΚΗΣ_ΠΑΘΟΛΟΓΙΑΣ', 'ΓΕΝΙΚΟΣ_ΧΕΙΡΟΥΡΓΟΣ', 'ΜΑΙΕΥΤΗΡΑΣ_ΓΥΝΑΙΚΟΛΟΓΟΣ', 'ΠΑΙΔΙΑΤΡΟΣ', 'ΑΝΑΙΣΘΗΣΙΟΛΟΓΟΣ', 'ΑΚΤΙΝΟΛΟΓΟΣ', 'ΠΑΘΟΛΟΓΟΣ', 'ΚΑΡΔΙΟΛΟΓΟΣ', 'ΟΡΘΟΠΕΔΙΚΟΣ_ΧΕΙΡΟΥΡΓΟΣ', 'ΝΕΥΡΟΛΟΓΟΣ', 'ΨΥΧΙΑΤΡΟΣ'.

-υποθέτουμε ότι κάθε διευθυντής γιατρός μπορεί να διευθύνει το πολύ 1 τμήμα

-υποθέτουμε ότι κάθε γιατρός που προσλαμβάνεται στο νοσοκομείο(νέο entry) αν έχει επόπτξη, αυτός θα είναι γιατρός που εργάζεται ήδη στο νοσοκομείο. (Δεν μπορεί να υπάρξει supervisor_id που να αναφέρεται σε entry που θα γίνει μελλοντικά)

-υποθέτουμε ότι υπάρχουν ακριβώς 3 διαφορετικοί δοιηκιτικοί ρόλοι: Διευθυντές, Γραμματείς και Λογιστές.
-υποθέτουμε ότι 2 τμήματα του νοσοκομείου δεν μπορούν να έχουν τον ίδιο διευθυντή.

-υποθέτουμε ότι οι κλίνες του νοσοκομείου κατηγοριοποιούνται βάση του αν ανήκουν σε μονόκλινο ή πολύκλινο δωμάτιο ή αν βρίσκονται σε μονάδα εντατικής θεραπίας.

-υποθέτουμε ότι μία κλίνη μπορεί να είναι είτε κατηλημένη, είτε ελεύθερη είτε υπό συντήρηση.

-Υποθέτουμε ότι για τον έλεγχο επικάλυψης στις ιατρικές πράξεις αλλά και στις βάρδιες δεν αρκεί η ημερομηνία οπότε προστέθηκε πεδίο DATETIME για να εξασφαλιστεί η τήρηση της οκτάωρης ανάπαυσης και η διαθεσιμότητα των χειρουργικών αιθουσών.

-Υποθέτουμε σταθερα οκτάωρα βαρδιών : 07:00-15:00, 15:00-23:00, 23:00-07:00.

-Υποθέτουμε ότι κάθε φάρμακο μπορεί να έχεις πολλές δραστικές ουσίες οι οποίες αποθηκεύονται ως ξεχωριστές εγγραφές σε απλοποιημένη μορφή. Έτσι η διαστάυρωση με τις αλλεργίες γίνεται με πλήρη ταύτιση του ονόματος της ουσίας.

-Υποθέτουμε ότι οι ειδικευόμενοι πρέπει να έχουν πάντα έναν επόπτη ενώ οι διευθυντές απαγορεύεται να έχουν επόπτη.

-Υποθέτουμε ότι το σύστημα υπολογίζει αυτόματα την πρόσθετη χρέωση μόνο αν οι ημέρες νοσηλείας ξεπερνούν τη Μέση Διάρκεια Νοσηλείας που ορίζεται από τον κωδικό ΚΕΝ.

Triggers :
Έχει γίνει η παραδοχή ότι η βάση δεδομένων πρέπει να εμποδίζει την εισαγωγή δεδομένων που παραβιάζουν τους κανόνες.

Απαγορεύεται η συνταγογράφηση φαρμάκου σε αλλεργικό ασθενή.
Απαγορεύεται ο προγραμματισμός βάρδιας σε άτομο που δεν έχει συμπληρώσει οκτάωρη ανάπαυση.
Απαγορεύεται η ανάθεση περισσότερων από τριών συνεχόμενων νυχτερινών βαρδιών.
Απαγορεύεται η εισαγωγή σε κλινή αν η κατάσταση της Δεν είναι "FREE".
Απαγορεύεται διπλή κράτηση αίθουσας χειρουργίου
Απαγορεύεται η συμμετοχή γιατρού σε δύο ταυτόχρονες επεμβάσεις.
Απαγορεύεται να ξεπεραστούν τα μέγιστα όρια βαρδιών ανά μήνα (15 για γιατρούς, 20 για νοσηλευτές, 25 για διοικητικούς).
Απαγορεύεται οι ειδικευόμενοι να μην έχουν επόπτοι ή να έχουν επόπτοι οι διευθυντές.


Για την εκπόνηση της εργασίας έγινε χρήση εργαλείων Τεχνητής Νοημοσύνης (LLM) για την παραγωγή ψεύτικων δεδομένων (mock data) σε μορφή CSV/Excel και τη βοήθεια στη δομή της τεκμηρίωσης.

Για τη βελτιστοποίηση των ερωτημάτων Queries αποφασίστηκε η δημιουργία indexes σε πεδία που χρησιμοποιούνται συχνά για φιλτράρισμα, όπως είναι οι ημερομηνίες εισαγωγής ασθενών και οι ειδικότητες των γιατρών. Η τεκμηρίωση για τα Q4 και Q6 θα περιλαμβάνει ανάλυση EXPLAIN ANALYZE για την επιβεβαίωση της ταχύτητας εκτέλεσης.
